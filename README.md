# People Pulse — KPI & Skill Management

ระบบทูดูลิสและบริหารทรัพยากรบุคคลสำหรับหัวหน้าทีมและฝ่ายบุคคล โดยให้การจัดการงานเป็นหน้าหลัก แล้วเชื่อมโปรเจกต์ หลักฐานผลงาน KPI สกิล แฟ้มพนักงาน ค่าตอบแทน แต้ม และรางวัลไว้ในที่เดียว

## ความสามารถหลัก

- ระบบเข้าใช้หลายคนด้วยบัญชีที่ยืนยันตัวตน แบ่งสิทธิ์เป็น HR / Admin, หัวหน้าทีม และพนักงาน พร้อมพักหรือเปิดสิทธิ์รายบัญชี
- หน้าจัดการผู้ใช้งานสำหรับผูกอีเมลเข้าสู่ระบบกับโปรไฟล์พนักงานหนึ่งคน และบันทึกการเข้าสู่ระบบครั้งล่าสุด
- พนักงานเห็นเฉพาะทูดูลิส ภารกิจ แฟ้มผลงาน แต้ม และของรางวัลของตัวเอง โดยมีการตรวจสิทธิ์ซ้ำที่ระบบหลังบ้านทุกครั้ง
- หัวหน้าทีมเห็นเฉพาะพนักงาน งาน โปรเจกต์ ผลประเมิน และหลักฐานของแผนกที่ได้รับมอบหมาย โดยไม่เห็นเงินเดือน เอกสารสมัครงาน หรือข้อมูลส่วนตัวละเอียด
- HR / Admin จัดการข้อมูลทุกส่วนและบัญชีผู้ใช้งานได้ทั้งหมด
- Dashboard สรุปคะแนนเฉลี่ย ความคืบหน้าการประเมิน และรายการที่ยังค้าง
- ทะเบียนพนักงาน พร้อมค้นหาและกรองตามแผนก
- แฟ้มพนักงานดิจิทัล พร้อมข้อมูลส่วนตัว การจ้างงาน การศึกษา ผู้ติดต่อฉุกเฉิน และสถานะความครบถ้วน
- รูปโปรไฟล์พนักงานอัปโหลดได้ และแสดงต่อเนื่องในรายชื่อ สกิล ค่าพลัง งาน โปรเจกต์ และหน้าตรวจประเมิน
- เช็กลิสต์เอกสารสมัครงาน อัปโหลด PDF/Word/รูปภาพ ตรวจผ่าน หรือส่งกลับให้แก้ไข
- สัญญาจ้างหลายเวอร์ชัน ต้องผูกไฟล์ต้นฉบับก่อนส่งลงนาม
- ลายเซ็นอิเล็กทรอนิกส์ พร้อมบันทึกชื่อ คำยินยอม บัญชีผู้ใช้ และวันเวลา
- แบบประเมิน KPI ตามตำแหน่งงานและน้ำหนักของแต่ละตัวชี้วัด
- Competency assessment ระดับ 1–5 และ Skill Readiness รายสายงาน
- โปรไฟล์สกิลรายบุคคล เปรียบเทียบระดับปัจจุบันกับเป้าหมาย พร้อมจุดแข็งและช่องว่างที่ควรพัฒนา
- กราฟใยแมงมุม 5 มิติและ Talent Fit จัดอันดับตำแหน่งงานที่เหมาะสมเบื้องต้น
- การ์ดค่าพลังพนักงานแบบโปรไฟล์มืออาชีพ มี OVR, Potential และ 6 ค่าพลัง: ความเร็วงาน ความเชี่ยวชาญ วิสัยทัศน์ ทีมเวิร์ก การแก้ปัญหา และภาวะผู้นำ
- Power Arena เลือกพนักงาน 2 คนมาเปรียบเทียบค่าพลังรายด้าน พร้อมสรุปส่วนต่างเพื่อใช้วางแผนโค้ชทีม
- People Decision Board ดู KPI สกิล Talent Fit เงินเดือน และแผนถัดไปของแต่ละคนในหน้าจอเดียว
- People Operating System ลงเวลาเข้า–ออก คำนวณนาทีมาสาย บันทึกขาดงาน ส่งคำขอลา และอนุมัติวันลาพร้อมประวัติผู้อนุมัติ
- Growth & Reward Path แสดงเงินเดือน เงินเพิ่มจากสกิล เควสต์ และความพร้อมเลื่อนตำแหน่งจาก KPI 40% สกิล 40% เควสต์ 15% และความสม่ำเสมอ 5%
- Skill-based Pay ยืนยันระดับสกิลจากผลประเมินและหลักฐาน เพิ่มค่าตอบแทนแบบตรวจสอบย้อนหลัง และป้องกันการเพิ่มซ้ำในระดับเดิม
- Smart Team Builder แนะนำทีมข้ามสายงานจากจุดแข็งและภาระงาน ก่อนสร้างโปรเจกต์หรือเควสต์ให้ทีม
- Action Center สำหรับติดตามการทดสอบสกิล อัปสกิล ทบทวนตำแหน่ง และทบทวนเงินเดือน
- กรอบเงินเดือนตามตำแหน่ง พร้อมบันทึกเงินเดือนและรอบทบทวนรายบุคคล
- Project Pulse ติดตามเจ้าของโปรเจกต์ กำหนดส่ง และความคืบหน้าจากงานจริง
- Smart To-do Board แยกงาน รีเควสต์ และภารกิจตามสถานะ พร้อมผู้รับผิดชอบ คะแนน และเปอร์เซ็นต์ความคืบหน้า
- เปิดระบบมาที่ทูดูลิสทันที พร้อมสรุปงานวันนี้ งานเกินกำหนด งานรอตรวจ และอัตราปิดงานในมุมมองแรก
- Today's Focus เรียงงานสำคัญตามกำหนดส่งและระดับความเร่งด่วน พร้อมปุ่มเริ่มงาน ส่งงาน หรือตรวจงานจากรายการ
- Master To-do List สลับได้ทั้งมุมมองรายการและ Kanban กรองตามผู้รับผิดชอบ วันนี้ งานเกินกำหนด 7 วันข้างหน้า ประเภทงาน แผนก และคำค้นหา
- UI แบบเว็บแอปสมัยใหม่ ใช้เมนูด้านข้างบนเดสก์ท็อป การ์ดที่อ่านง่าย พื้นที่ว่างชัดเจน และเมนูแนวนอนที่รองรับการสัมผัสบนมือถือ
- Interactive 3D Office World รวมตัวละครทุกคนไว้ในออฟฟิศสามมิติแบบเกม หมุน–ซูมกล้องได้ ตัวละครว่างเลือกเส้นทางเดินเอง ส่วนคนมีงานจะแสดงท่าทางทำงานเร็วหรือชิลตามภาระจากทูดูลิส
- Work Proof Center ส่งหลักฐานงานเป็นลิงก์วิดีโอ Drive โพสต์ Social Media เอกสาร Artwork โค้ด CRM Ticket หรือไฟล์แนบ พร้อมขั้นตอนรอตรวจ อนุมัติ และส่งกลับแก้ไข
- Employee Work Portfolio รวมงานที่เสร็จและหลักฐานไว้เป็นแฟ้มรายบุคคล พร้อมค้นหาจากชื่อคน โปรเจกต์ ชื่องาน ชื่อไฟล์ ลิงก์ หรือรายละเอียดการส่งมอบ
- Portfolio Finder กรองตามพนักงาน โปรเจกต์ แผนก และสถานะ เปิดไฟล์หรือลิงก์ย้อนกลับ ดูผู้ตรวจ KPI สกิล คะแนนรวม และส่งออกแฟ้มเป็น CSV
- คำแนะนำหลักฐานตามตำแหน่ง ครอบคลุมฝ่ายขาย การตลาด บริการลูกค้า นักพัฒนา HR และนักตัดต่อวิดีโอ
- Mission Points ให้แต้มอัตโนมัติหนึ่งครั้งเมื่อปิดงานหรือภารกิจสำเร็จ พร้อมโบนัสส่งก่อนกำหนด 100 แต้ม หรือส่งตรงเวลา 50 แต้มหลังหลักฐานผ่านการตรวจ
- Points Operations ประมวลผลแต้มผลประเมินรายเดือนด้วยสูตรคะแนนรวม × 10 สูงสุด 1,000 แต้ม และรันซ้ำเดือนเดิมได้โดยไม่สร้างแต้มซ้ำ
- บันทึกแต้มเข้า–ออกจากการเข้างาน ภารกิจ โบนัส คุณภาพงาน และวินัย พร้อมวันที่ เหตุผล หลักฐาน ผู้บันทึก และประวัติตรวจสอบย้อนหลัง
- กติกาความเป็นธรรมแยกการลาที่อนุมัติแล้วเป็น 0 แต้ม ไม่ใช้เป็นบทลงโทษ และเตือนให้ตรวจสอบข้อเท็จจริงก่อนหักแต้ม
- Points Leaderboard และ Reward Store สำหรับสะสมแต้ม แลกรางวัล และติดตามคำขอแลก มีคูปองเงินสด 100 บาท ราคา 1,000 แต้ม กิฟต์วอเชอร์ 500 บาท ราคา 5,000 แต้ม และ iPhone 18 ราคา 500,000 แต้ม
- สูตรคะแนนรวม KPI 70% และสกิล 30%
- สูตร OVR ใช้ค่าเฉลี่ยพลังจากสกิลและงาน 70% ร่วมกับ KPI 30% โดยจำกัดคะแนนสูงสุดที่ 99
- บันทึกและแก้ไขผลแยกตามรอบประเมิน
- เพิ่มพนักงานใหม่และส่งออกรายงาน CSV ภาษาไทยพร้อมรายละเอียดสกิลรายคน
- ฐานข้อมูล Cloudflare D1 สำหรับข้อมูลพนักงาน ประวัติการประเมิน เงินเดือน เอกสาร และสัญญา
- Cloudflare R2 สำหรับเก็บไฟล์เอกสารพนักงานแบบถาวร

## เริ่มใช้งานในเครื่อง

ต้องใช้ Node.js 22.13 ขึ้นไป

```bash
npm install
npm run dev
```

สร้างและตรวจระบบ:

```bash
npm run build
npm test
npm run lint
```

## โครงสร้างข้อมูล

- `employees` เก็บทะเบียนพนักงาน ตำแหน่ง ผู้จัดการ และผลล่าสุด
- `user_accounts` เก็บอีเมลเข้าสู่ระบบ บทบาท โปรไฟล์พนักงานที่ผูก แผนก สถานะ และการเข้าสู่ระบบล่าสุด
- `evaluations` เก็บคะแนน KPI คะแนนสกิล บันทึกผู้ประเมิน และรอบประเมิน
- `hr_profiles` เก็บเงินเดือนปัจจุบันและรอบทบทวนค่าตอบแทน
- `attendance_records` เก็บเวลาเข้า–ออก สถานะมาสาย ขาดงาน วันลา และประวัติการอนุมัติ
- `skill_achievements` เก็บระดับสกิลที่ยืนยันแล้ว หลักฐาน ผู้ตรวจ และเงินเพิ่มรายเดือนของแต่ละระดับ
- `talent_actions` เก็บแผนทดสอบ อัปสกิล ทบทวนตำแหน่ง และเงินเดือน
- `projects` เก็บโปรเจกต์ เจ้าของ สถานะ และกำหนดส่ง
- `work_items` เก็บงาน รีเควสต์ ภารกิจ ผู้รับผิดชอบ ความคืบหน้า และคะแนน
- `work_submissions` เก็บลิงก์ ไฟล์หลักฐาน ประวัติการส่ง สถานะตรวจ และหมายเหตุผู้ตรวจ
- `point_ledger` เก็บประวัติแต้มเข้าออกของพนักงานแต่ละคน
- `point_events` เก็บประเภทเหตุการณ์ วันที่ เหตุผล ลิงก์หลักฐาน และผู้บันทึก เพื่อใช้ตรวจสอบที่มาของแต้มและบทลงโทษ
- `rewards` เก็บแคตตาล็อกรางวัล ราคาแต้ม และจำนวนคงเหลือ
- `reward_redemptions` เก็บคำขอแลกรางวัลและสถานะการอนุมัติ
- `employee_profiles` เก็บข้อมูลส่วนตัว การศึกษา ประสบการณ์ รายละเอียดการจ้างงาน และข้อมูลไฟล์รูปโปรไฟล์
- `application_documents` เก็บข้อมูลกำกับไฟล์สมัครงาน สถานะตรวจ และผู้ตรวจ
- `employment_contracts` เก็บสัญญา เวอร์ชัน สถานะ หลักฐานคำยินยอม และการลงนาม
- `lib/kpi-data.ts` กำหนด KPI และ competency template ของแต่ละตำแหน่ง
- `drizzle/` เก็บ migration ที่ใช้สร้างฐานข้อมูล D1

การเผยแพร่ผ่าน OpenAI Sites จะสร้างและผูก D1 binding ชื่อ `DB` และ R2 binding ชื่อ `FILES` จาก `.openai/hosting.json` โดยอัตโนมัติ
