# People Pulse — KPI & Skill Management

ระบบบริหารทรัพยากรบุคคลสำหรับฝ่ายบุคคลและหัวหน้าทีม เชื่อมแฟ้มพนักงาน เอกสารสมัครงาน สัญญาจ้าง ลายเซ็นอิเล็กทรอนิกส์ ผลประเมิน KPI ระดับสกิล งาน โปรเจกต์ ภารกิจ ค่าตอบแทน และรางวัลไว้ในที่เดียว

## ความสามารถหลัก

- Dashboard สรุปคะแนนเฉลี่ย ความคืบหน้าการประเมิน และรายการที่ยังค้าง
- ทะเบียนพนักงาน พร้อมค้นหาและกรองตามแผนก
- แฟ้มพนักงานดิจิทัล พร้อมข้อมูลส่วนตัว การจ้างงาน การศึกษา ผู้ติดต่อฉุกเฉิน และสถานะความครบถ้วน
- รูปโปรไฟล์พนักงานอัปโหลดได้ และแสดงต่อเนื่องในรายชื่อ สกิล ค่าพลัง งาน โปรเจกต์ และหน้าตรวจประเมิน
- เช็กลิสต์เอกสารสมัครงาน อัปโหลด PDF/Word/รูปภาพ ตรวจผ่าน หรือส่งกลับให้แก้ไข
- สัญญาจ้างหลายเวอร์ชัน ต้องผูกไฟล์ต้นฉบับก่อนส่งลงนาม
- ลายเซ็นอิเล็กทรอนิกส์ พร้อมบันทึกชื่อ คำยินยอม บัญชีผู้ใช้ และวันเวลา
- แบบประเมิน KPI ตามตำแหน่งงานและน้ำหนักของแต่ละตัวชี้วัด
- Competency assessment ระดับ 1–5 และ Skill Readiness รายสายงาน
- โปรไฟล์สกิลรายบุคคล เปรียบเทียบระดับปัจจุบันกับเป้าหมาย พร้อมจุดแข็งและช่องว่างที่ควรพัฒนา
- กราฟใยแมงมุม 5 มิติและ Talent Fit จัดอันดับตำแหน่งงานที่เหมาะสมเบื้องต้น
- การ์ดค่าพลังพนักงานแบบเกมกีฬา มี OVR, Potential และ 6 ค่าพลัง: ความเร็วงาน ความเชี่ยวชาญ วิสัยทัศน์ ทีมเวิร์ก การแก้ปัญหา และภาวะผู้นำ
- Power Arena เลือกพนักงาน 2 คนมาเปรียบเทียบค่าพลังรายด้าน พร้อมสรุปส่วนต่างเพื่อใช้วางแผนโค้ชทีม
- People Decision Board ดู KPI สกิล Talent Fit เงินเดือน และแผนถัดไปของแต่ละคนในหน้าจอเดียว
- Action Center สำหรับติดตามการทดสอบสกิล อัปสกิล ทบทวนตำแหน่ง และทบทวนเงินเดือน
- กรอบเงินเดือนตามตำแหน่ง พร้อมบันทึกเงินเดือนและรอบทบทวนรายบุคคล
- Project Pulse ติดตามเจ้าของโปรเจกต์ กำหนดส่ง และความคืบหน้าจากงานจริง
- Smart To-do Board แยกงาน รีเควสต์ และภารกิจตามสถานะ พร้อมผู้รับผิดชอบ คะแนน และเปอร์เซ็นต์ความคืบหน้า
- Work Proof Center ส่งหลักฐานงานเป็นลิงก์วิดีโอ Drive โพสต์ Social Media เอกสาร Artwork โค้ด CRM Ticket หรือไฟล์แนบ พร้อมขั้นตอนรอตรวจ อนุมัติ และส่งกลับแก้ไข
- คำแนะนำหลักฐานตามตำแหน่ง ครอบคลุมฝ่ายขาย การตลาด บริการลูกค้า นักพัฒนา HR และนักตัดต่อวิดีโอ
- Mission Points ให้แต้มอัตโนมัติหนึ่งครั้งเมื่อปิดงานหรือภารกิจสำเร็จ
- Points Leaderboard และ Reward Store สำหรับสะสมแต้ม แลกรางวัล และติดตามคำขอแลก
- สูตรคะแนนรวม KPI 70% และสกิล 30%
- สูตร OVR ใช้ค่าเฉลี่ยพลังจากสกิลและงาน 70% ร่วมกับ KPI 30% โดยจำกัดคะแนนสูงสุดที่ 99
- บันทึกและแก้ไขผลแยกตามรอบประเมิน
- เพิ่มพนักงานใหม่และส่งออกรายงาน CSV ภาษาไทยพร้อมรายละเอียดสกิลรายคน
- ฐานข้อมูล Cloudflare D1 สำหรับข้อมูลพนักงาน ประวัติการประเมิน เงินเดือน เอกสาร และสัญญา
- Cloudflare R2 สำหรับเก็บไฟล์เอกสารพนักงานแบบถาวร

## เริ่มใช้งานในเครื่อง

ต้องใช้ Node.js 22.13 ขึ้นไป

```bash
npm install
npm run dev
```

สร้างและตรวจระบบ:

```bash
npm run build
npm test
npm run lint
```

## โครงสร้างข้อมูล

- `employees` เก็บทะเบียนพนักงาน ตำแหน่ง ผู้จัดการ และผลล่าสุด
- `evaluations` เก็บคะแนน KPI คะแนนสกิล บันทึกผู้ประเมิน และรอบประเมิน
- `hr_profiles` เก็บเงินเดือนปัจจุบันและรอบทบทวนค่าตอบแทน
- `talent_actions` เก็บแผนทดสอบ อัปสกิล ทบทวนตำแหน่ง และเงินเดือน
- `projects` เก็บโปรเจกต์ เจ้าของ สถานะ และกำหนดส่ง
- `work_items` เก็บงาน รีเควสต์ ภารกิจ ผู้รับผิดชอบ ความคืบหน้า และคะแนน
- `work_submissions` เก็บลิงก์ ไฟล์หลักฐาน ประวัติการส่ง สถานะตรวจ และหมายเหตุผู้ตรวจ
- `point_ledger` เก็บประวัติแต้มเข้าออกของพนักงานแต่ละคน
- `rewards` เก็บแคตตาล็อกรางวัล ราคาแต้ม และจำนวนคงเหลือ
- `reward_redemptions` เก็บคำขอแลกรางวัลและสถานะการอนุมัติ
- `employee_profiles` เก็บข้อมูลส่วนตัว การศึกษา ประสบการณ์ รายละเอียดการจ้างงาน และข้อมูลไฟล์รูปโปรไฟล์
- `application_documents` เก็บข้อมูลกำกับไฟล์สมัครงาน สถานะตรวจ และผู้ตรวจ
- `employment_contracts` เก็บสัญญา เวอร์ชัน สถานะ หลักฐานคำยินยอม และการลงนาม
- `lib/kpi-data.ts` กำหนด KPI และ competency template ของแต่ละตำแหน่ง
- `drizzle/` เก็บ migration ที่ใช้สร้างฐานข้อมูล D1

การเผยแพร่ผ่าน OpenAI Sites จะสร้างและผูก D1 binding ชื่อ `DB` และ R2 binding ชื่อ `FILES` จาก `.openai/hosting.json` โดยอัตโนมัติ
